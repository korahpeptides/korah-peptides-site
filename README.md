# korah-peptides-site

Pre-launch informational website for Korah Peptides.

## Status

This is a non-transactional website. It does not accept orders,
payments, prescriptions, or medical information.

## Files

- `index.html` — main page
- `styles.css` — visual styling
- `script.js` — optional browser behaviour
- `korah-peptides-ad.jpg` — website image

## Deployment

The site is deployed through Cloudflare Pages from the `main` branch.
